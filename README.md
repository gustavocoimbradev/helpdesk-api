# Helpdesk API

API REST desenvolvida em C# com ASP.NET Core para gerenciamento de chamados internos de suporte técnico.

O projeto permite criar, consultar, atualizar e excluir chamados, além de realizar filtros combinados por status, prioridade, solicitante e responsável.

## Tecnologias

- C#
- ASP.NET Core Web API
- Entity Framework Core
- SQLite
- OpenAPI
- Scalar API Reference

## Funcionalidades

- Criação de chamados
- Listagem de todos os chamados
- Consulta de chamado por ID
- Atualização parcial de chamados
- Exclusão de chamados
- Atribuição de responsável
- Alteração de status e prioridade
- Validação das entidades relacionadas
- Filtros cumulativos por:
  - status
  - prioridade
  - solicitante
  - responsável
- Listagem de status
- Listagem de prioridades
- Dados iniciais por meio de seeds
- Documentação interativa da API
